# DiagMoteur — version en ligne

Diagnostic de défauts de roulements (vibration + courant) — projet de fin d'études.
Version légère : modèles « caractéristiques physiques + gradient boosting » (meilleurs en test) ;
les CNN sont évalués dans la page Résultats mais ne sont pas chargés (mémoire limitée).
Données : Paderborn University Bearing DataCenter (Lessmeier et al., 2016), usage académique.
